# Sorteo de Amigo Invisible

Aplicación web moderna desarrollada con **Tailwind CSS**, **Alpine.js** y **Canvas Confetti** para organizar sorteos de Amigo Invisible de forma rápida, limpia y completamente privada desde el navegador.

## Características

- **Gestión de Participantes**: Añade nombres y correos opcionales de forma sencilla.
- **Reglas y Exclusiones**: Configura restricciones (por ejemplo: "Persona A no puede regalar a Persona B").
- **Presupuesto y Fecha**: Define las condiciones del evento visibles para todos.
- **Revelación Privada**: Sistema de tarjetas individuales con bloqueo para evitar spoilers al pasar el dispositivo.
- **Diseño Responsivo y Oscuro**: Interfaz moderna inspirada en herramientas profesionales con soporte móvil completo.

## Uso

1. Abre el archivo `index.html` en cualquier navegador web moderno.
2. Añade al menos 3 participantes.
3. Configura reglas de exclusión si lo deseas.
4. Pulsa **¡Realizar Sorteo!**.
5. Pasa el dispositivo a cada participante para que descubra su amigo invisible de forma secreta.
